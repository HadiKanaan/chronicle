# Chronicle of the Velvet Lies — Project Summary

> **Purpose of this document:** a complete, self-contained briefing on the project,
> written so it can be handed to an AI assistant to generate a PowerPoint
> presentation. A suggested slide outline is included at the end. The deck should
> target a ~10-minute capstone presentation for an AI course.

---

## 1. One-line pitch

**Chronicle of the Velvet Lies** is a backend-authoritative **living-world RPG
simulation**: an entire medieval town that runs itself with ~13 machine-learning
models and a **local large language model**, where the player inherits a
villager's life, talks to people who *remember* them, and watches an emergent
narrative unfold — all running **on-device, no cloud**.

## 2. What it is

- A single deeply-simulated town, **Aldenmoor** (a 64×64 tile world), populated by
  **~80 NPCs** across **three tiers of simulation depth** and **four factions**.
- The player "inherits" the life of one host villager and explores, talks to
  townsfolk, and influences the world.
- NPCs have moods, memories, relationships, occupations, and opinions of the
  player that **persist** and evolve. Rumors spread between them and distort.
- A **Demon Lord** stirs beyond the eastern hills and makes one decision each
  dawn, eroding faction morale and seeding fear — driving an **emergent story**
  that is never scripted.
- A wider **continent** frames the town (a graphical world map), generated by the
  same ML that built the valley.

## 3. Technology stack

| Layer | Technology |
|---|---|
| Backend | Python, **FastAPI**, **SQLite** (JSON blobs), **scikit-learn** |
| Machine learning | scikit-learn (decision trees, KMeans, logistic regression, random forests), NumPy/SciPy |
| Language model | **Local Qwen LLM via Ollama** (CPU-only); chosen over the spec's Gemma 3 1B for quality |
| Frontend | **React + Vite**, HTML5 Canvas renderer |
| Audio | **Howler.js** (Web Audio), Azure Speech / Azure OpenAI Realtime for NPC voices |
| Process | **Spec-Kit** spec-driven development, day-by-day on `main` |

## 4. Core architecture principle

**The backend is the single source of truth; the frontend is a dumb renderer.**

- All simulation, ML, and persistence live in the backend. The frontend only
  **renders** the authoritative state and **posts intents** (move, talk, pause,
  toggles) — it never owns game logic.
- The frontend polls `GET /api/state` every **200 ms** for a compact render
  payload; the canvas tweens/animates between polls for smoothness.
- State is persisted in SQLite as JSON blobs; the static map grid is split into a
  write-once table so the hourly tick stays cheap.
- Concurrency is disciplined with a simulation lock (`_sim_lock`): slow LLM calls
  run **outside** the lock against a snapshot; only the read-modify-write of a
  card holds it, so the world clock never stalls.
- Convention: **one system per file** (e.g. `behavior.py`, `rumors.py`,
  `factions.py`, `tiers.py`, `conversation.py`, `voice.py`, `continent.py`).

## 5. The machine-learning layer (the academic centerpiece)

The project implements **13 of a planned 14 ML models**, all trained in-process
on synthetic/heuristic data and used at runtime. House pattern: a rule function →
synthetic samples → trained model → predict-with-rule-fallback (so it degrades
gracefully if scikit-learn is unavailable).

1. **Biome classifier** (KMeans) — classifies climate cells into biomes; used for
   both the town and every cell of the continent.
2. **Civilization-seed / settlement-suitability model** — scores where towns and
   capitals should sit.
3. **NPC behavior classifier** (decision tree, 7 states) — picks each NPC's
   hourly behavior (working, traveling, socializing, fleeing, etc.).
4. **NPC mood model** — rolls daily moods per NPC.
5. **Weather model** (classifier) — daily weather (clear / rain / fog / storm).
6. **Conversation sentiment scorer** (TF-IDF + logistic regression) — scores the
   player's message tone to shift an NPC's disposition.
7. **Tile-interaction scorer** — chooses an NPC's destination kind
   (home/work/tavern/market/plaza), replacing hand-coded if/else with a model.
8. **Witness memory tagger** — decides which NPCs actually *witness* an event
   (spends each NPC's perception skill), gating what enters memory and rumor.
9. **NPC relationship-drift model** — relationships between NPCs evolve over time.
10. **Rumor propagation + distortion model** — rumors spread along the social
    graph and mutate as they travel.
11. **Player-reputation model** — how factions regard the player.
12. **Faction-relationship model** — inter-faction dynamics.
13. **Country-property generator** (random forest, multi-output) — correlated
    national stats (naval power, timber, agriculture, minerals, military,
    population) with hard real-world constraints (landlocked → no navy, arid → no
    timber).

Supporting ML technique: **RAG memory retrieval** — TF-IDF + cosine similarity
over each NPC's memory buffer to inject the *relevant* memories into a
conversation prompt, not just the most recent.

## 6. The LLM conversation system

- **Click a villager (or press E) to talk.** Replies come from a **local Qwen
  LLM** via Ollama — fully offline.
- Each reply is grounded in: the NPC's persona, current mood, disposition toward
  the player, **RAG-retrieved relevant memories**, and known rumors.
- The model writes **only the in-character reply**; mood, sentiment delta, and
  memory are computed cheaply backend-side (avoiding slow, brittle JSON output).
- **Persistence:** conversations are remembered; sentiment accumulates, shifting
  an NPC from "neutral" → "friendly" → "warm and trusting" (or hostile) over time.
- **Performance engineering (CPU-only is hard):** Ollama prompt **prefix-cache
  warming** on dialogue-open and after each reply; static-first prompt structure
  so the cache is reused; measured warm turns dropped from ~12 s to ~4–6 s.
- The **Demon Lord's** daily decision is a **schema-constrained** LLM call (one of
  five action types), with validation, re-roll, and a rule-based fallback.

## 7. Emergent simulation systems

- **Living world clock:** real time advances in-game hours; an hourly tick
  re-classifies behavior and paths NPCs (BFS) toward goals; a dawn tick runs the
  full ML batch (weather, moods, relationship drift, rumor spread, faction
  updates, Demon-Lord decision).
- **Demon Lord (Vhal'Zur the Veiled Flame):** injected into the live world;
  decides one action per dawn (spread fear, raid supplies, demand tribute, corrupt
  an official, dark omen) that shifts faction morale, traumatizes victims, and
  births a high-drama rumor.
- **Rumor propagation + distortion:** rumors spread NPC-to-NPC along Tier-1
  relationships, weighted by personality, and *mutate* as they travel; they color
  dialogue and age out over time.
- **Dynamic NPC tiers — "an LRU of personhood":** talk to a background villager a
  few times and they're **promoted** to a deeply-simulated Tier-1 character
  (seeded a backstory, wired into the social graph, LLM-enriched); to hold the ~10
  Tier-1 budget, the least-recently-talked-to one is **demoted** (keeping all
  memories, so returning re-promotes them whole). *The player's attention decides
  who becomes a real person.*

## 8. World, exploration, and the continent map

- **Fog of war:** computed backend-side from the host NPC's position; explored
  tiles persist across restarts and reveal as you walk.
- **Continent overlay (press M):** a graphical world map that frames the town.
  The **same biome KMeans** that classified Aldenmoor classified every cell of the
  continent; KMeans clusters high-suitability land into **nations** with borders,
  rivers, capitals, and points of interest. Biome climate is driven by a 2D warmth
  field (not just latitude) so biomes form organic regions, and it's rendered as
  an **aged-atlas** (parchment, coastal shallows, compass rose, "you are here"
  pin). *Honest framing: only Aldenmoor is deeply simulated; the continent is
  graphical context.*

## 9. Audio (Day 9)

- **Original soundtrack** (by Ivan Duch): two pools — peaceful by day, ominous by
  night — that crossfade on the day/night flip.
- **Ambient layers** keyed off weather + time of day (rain, storm + thunder, wind,
  birds, night), with footsteps on movement.
- **NPC voices:** backend-mediated text-to-speech (Azure Speech / Azure OpenAI
  Realtime), with deterministic per-NPC voice selection and a disk cache; the key
  never reaches the browser.
- **Graceful degradation everywhere:** any missing audio asset simply no-ops —
  the game is never broken by absent sound.

## 10. The AA pixel-art UI overhaul (Day 10)

A presentation-layer pass that makes it look like a finished AA game, with **no
gameplay/ML changes** — the backend stayed authoritative, the frontend stayed a
dumb renderer:

- **Full-screen responsive camera** (fills the window, culls to visible tiles,
  device-pixel-ratio aware).
- **Diegetic game HUD** — edge-anchored framed plates: world status (day/clock/
  weather), collapsible factions and Demon-Lord cards, town-gossip, and a bottom
  toast feed.
- **Cohesive art direction** — dark slate + aged-parchment + muted gold, ember-red
  reserved for the Demon Lord, bundled pixel fonts, subtle motion, screen
  vignette.
- **Acquaintances / relationships panel** — the last people you've spoken to, each
  with a sprite portrait, mood, and how they feel about you (derived from existing
  data only).
- **Village minimap** — a fog-honoring corner overview with a pulsing player blip
  and the camera viewport.
- **Pause menu** — themed tabs for Sound, Debug, How-to-Play, and Regenerate.
- **Title splash** ("Click to begin") that also satisfies browser audio-autoplay
  unlock.

## 11. Engineering challenges & how they were solved

- **CPU-only LLM latency** → prompt prefix-cache warming, static-first prompts,
  reply-only generation, RAG to keep prompts lean.
- **Concurrency** (a background world clock + LLM calls + player input) → a
  simulation lock with slow work done outside it; serialized player moves.
- **Robustness** → graceful fallbacks throughout (ML → rules, missing audio →
  silence, missing fonts → system fonts); audio failures can never freeze the
  game (hardened after a live screen-share-with-audio bug suspended the Web Audio
  context and stalled movement).
- **Determinism & persistence** → seeded generation, SQLite-backed state that
  survives restarts, write-once static map data.

## 12. Development methodology

- Built with **Spec-Kit spec-driven development**: specify → plan → tasks →
  implement, iterated **day-by-day** on `main` (Days 1–10), one cohesive
  increment per day.
- Backend is the test home: a green pytest suite (200+ tests) guards the
  simulation, ML, and conversation layers; the frontend stays test-light.

## 13. Day-by-day progression (timeline)

- **Days 1–2:** world generation — terrain, ~80 NPCs in 3 tiers, 4 factions, ML
  biome + civilization-seed models, host selection.
- **Day 3:** canvas rendering — tilemap, character sprites, scrolling camera,
  day/night tint, HUD.
- **Day 4:** ML behavior layer — live world clock, behavior classifier,
  pathfinding, daily mood/weather/rumor ticks.
- **Day 5:** local LLM conversations — click-to-talk, memory recall, persistent
  sentiment.
- **Day 6:** Demon Lord + rumor propagation — emergent dawn decisions, gossip
  spreading along relationships.
- **Day 7:** fog of war + the ML-generated continent map; faction-model redesign;
  the 4-model ML batch.
- **Day 8:** visual flavor (building/decoration/prop sprites, animation, weather
  overlays), RAG memory retrieval, conversation speedups, dynamic tier
  promotion/demotion, ML models 5 & 6 → 13/14 registry.
- **Day 9:** audio — day/night OST, weather ambience, local-mediated NPC voices.
- **Day 10:** AA pixel-art UI overhaul — full-screen HUD, minimap, relationships
  panel, themed menus, continent reskin.

## 14. Demo highlights (what to show live)

- Walk the living town (animated NPCs, day/night, weather, fog revealing).
- Talk to a villager → grounded, in-character reply; watch their disposition shift
  and the Acquaintances panel update.
- Talk to a background villager a few times → **promotion** to a real character.
- Trigger a dawn tick → factions shift, moods change, a rumor is born, the Demon
  Lord acts — the whole ML batch reacting at once.
- Open the continent map → the same biome model scaled to a whole continent.
- Note the OST shifting with day/night and NPC voices.
